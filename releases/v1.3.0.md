# MacMural 1.3.0

Configurable shortcuts for the global drawing toggle, tools, clear, undo/redo, line widths, finish, and hold-to-interact.

- Open **MacMural’s menu bar icon → Keyboard Shortcuts…**, click a shortcut, press your keys, and click **Apply**.
- Shortcuts persist after quitting, and help and toolbar hints reflect your choices.
- Duplicate bindings and enabled macOS shortcut conflicts are rejected. If a new global shortcut cannot be registered, the previous bindings stay active.
- Keep or disable the optional **Hyper+D** aliases. **Restore Defaults** resets the editor; click Apply to save.
- The default toggle is now **Control + Shift + D (⌃⇧D)**, leaving Command + Option + D available for the macOS Dock.
- **Esc** always finishes drawing. The hold-to-interact key is a single key without modifiers; it defaults to **Space**.

Requires macOS 13 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

Download `MacMural.zip`, unzip it, quit any running copy of MacMural, and replace **MacMural.app** in **Applications**. Open the app, then choose **Keyboard Shortcuts…** from its menu bar icon.

Or install from the Homebrew tap:

```sh
brew install --cask henrikhestnes/tap/macmural
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macmural`.

This build is ad-hoc signed and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
