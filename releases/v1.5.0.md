# MacMural 1.5.0

Opening MacMural now starts drawing mode right away.

- Launching the app from Applications, Spotlight, or the Dock opens the drawing overlay immediately.
- Opening the app again while it is already running also starts drawing mode instead of showing the welcome window.
- The welcome window still appears once on the very first manual launch and remains available in **Shortcuts & Help…**.
- Login startup stays quiet, with drawing off and the welcome window hidden.

Requires macOS 13 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

Download `MacMural.zip`, unzip it, quit any running copy, and replace **MacMural.app** in **Applications**.

```sh
brew install --cask henrikhestnes/tap/macmural
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macmural`.

This build is ad-hoc signed and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
