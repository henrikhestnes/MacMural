# MacMural 1.4.0

Launch at login, enabled by default after the installed app is opened for the first time.

- **Launch at Login** in the menu bar lets you turn automatic startup off or on.
- The app respects later changes made in MacMural or macOS System Settings and does not automatically re-enable a disabled login item.
- If macOS needs approval, **Open Login Settings…** takes you to the relevant controls. Registration errors can be inspected from the menu.
- Login startup is quiet, with drawing off and the welcome window hidden. The welcome window appears once on the first manual launch and remains available in **Shortcuts & Help…**.
- Development builds in `dist/` leave login items unchanged. Install the app in `/Applications` or your user’s `Applications` folder and reopen it to enable the default.

Requires macOS 13 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

Download `MacMural.zip`, unzip it, quit any running copy, and replace **MacMural.app** in **Applications**. Open MacMural once so it can request launch at login. Complete any approval requested by macOS.

```sh
brew install --cask henrikhestnes/tap/macmural
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macmural`.

This build is ad-hoc signed and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper. Native login-item registration with this signature still needs a manual check on an installed copy before publishing.
